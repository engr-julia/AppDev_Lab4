# 📘 Lab4.php

## 📄 Description
Lab4.php is a PHP script that demonstrates the use of loops and conditional statements by checking the divisibility of numbers from 1 to 100.

## ⚙️ Functionality
- Prints "Divisible to 3 and 5" if a number is divisible by both 3 and 5.
- Prints "Divisible to 3" if only divisible by 3.
- Prints "Divisible to 5" if only divisible by 5.
- Otherwise, it prints the number itself.

## 🛠 Concepts Used
- For loop
- If-else statements
- Modulo operator (%)

## 🚀 How to Run
1. Place the file inside your local server folder (e.g., www in Laragon or htdocs in XAMPP).
2. Start your local server.
3. Open your browser.
